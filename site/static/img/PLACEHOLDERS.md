# Image slots the site can use from you

Everything in this folder is generated by `port/tools/site-shots.sh` (the game's own shot modes), except the tiles
and the 88×31 badges. These are the slots where your own pictures would beat a generated frame. Drop a file at the
name given and tell me; I wire it into the page. Until then the page uses the generated frame in the last column
(or has no slot at all).

| Slot / file name | Size (px) | What it would show | Used on | Stand-in today |
|---|---|---|---|---|
| `memory-original.jpg` | 1280×720 (16:9) | A photo or screenshot of the original iOS Eden (2010–2014): your own old device, world or build | Home "Remember Eden?" box, About | none (box has no picture) |
| `memory-build-1.jpg` … `-3.jpg` | 1280×720 (16:9) | Your own builds in today's version: castles, cities, anything | Screenshots | `water-noon.jpg`, `snow-noon.jpg`, `ambient-canopy.jpg` |
| `hero.jpg` | 1920×1080 (16:9) | A better hero than the generated riverbank | Home hero, OpenGraph card (WS.8) | `clear-noon-level.jpg` |
| `device-ipad.jpg` | 1280×720 (16:9) | The game running on a real iPad/iPhone | Download (iOS), Screenshots | `ui-hud.jpg` |
| `multiplayer.jpg` | 1280×720 (16:9) | Two players in one world | Help › Multiplayer | `ui-mp-list.jpg` |
| `mod-example.jpg` | 1280×720 (16:9) | A mod block or Lua script in action | Modding | `ui-mods.jpg` |

The sizes are suggestions, not limits: larger and sharper is welcome (pages show images at 640 CSS px wide, so 1280×720 is a good size for Retina screens; keep the 16:9 shape or tell me). No per-image size cap. The home-page budget in `python3 site/build.py --check` counts HTML, CSS and fonts only, not images.
