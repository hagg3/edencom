Modding

Eden: Community Edition can load new blocks, textures and Lua scripts from a folder, with no rebuild. A mod is a pack: a folder with a pack.json, some 32×32 PNG tiles and, if you want behaviour, a script. Worlds that use a pack keep working if you remove it: the blocks show as a magenta "missing" block and nothing is lost.

The path, in order

  1. Make your first block. One tile, one block, five minutes: the step-by-step guide.
  2. Learn the pack format. Tiles, sounds, blocks and their traits, validation messages: Blocks and packs.
  3. Add behaviour with Lua. A sandboxed script per pack with an eden.* API, events and budgets: Lua scripts.
  4. Drive the world from text. The same small language runs in command blocks and in the in-game console: how it works and every verb and setting.

Sharing and help

Packs install from a zip and show up in the in-game mod manager. Ask questions, show what you made and find other modders on the Discord. Bugs and requests go to GitHub issues.
