Download

Beta {{version}} is free, and the source is open (GPLv3). The builds are unsigned: your system will warn you the first time, and the steps below get past that. All files are on the latest release page.

macOS (Apple silicon)

Emod-{{version}}-macos-arm64.tar.gz

  1. Unpack it. You get a folder called Emod.
  2. The app is not notarized, so macOS blocks it. In Terminal, once: xattr -dr com.apple.quarantine Emod
  3. Run Emod/emod from Terminal (./Emod/emod), or double-click it in Finder.

Windows (64-bit)

Emod-{{version}}-windows-x64-portable.zip

  1. Unzip it somewhere you own, like your Documents folder. It runs from where it is: nothing is installed.
  2. Run eden.exe. If SmartScreen says "Windows protected your PC", choose More info, then Run anyway.

Linux (64-bit)

Emod-{{version}}-linux-x64.tar.gz

  1. Unpack it: tar xzf Emod-{{version}}-linux-x64.tar.gz
  2. Run ./Emod/emod. It needs the usual system libraries: OpenGL, X11 or Wayland, curl and audio.

iPhone and iPad

Emod-{{version}}-ios-unsigned.ipa

Apple only runs signed apps, so this .ipa needs a tool that signs it with your own Apple ID. iOS 15 or newer.

Android is planned, not built yet.

What you need

  • A graphics card or chip with OpenGL 3.3 on a computer (OpenGL ES 3.0 on iOS). Anything from the last decade has it.
  • About 1 GB free disk for the game and a few worlds. Worlds you download can be large.
  • An iPad Air 2 or newer, or an iPhone with iOS 15, for the iOS build.

Where your worlds are saved

SystemFolder
macOS~/Library/Application Support/Emod
Linux~/.local/share/emod/Documents
Windows%APPDATA%\Emod\Documents
iPhone, iPadFiles app, On My iPad, Emod

This is a separate folder from the old Eden app, so the two never touch each other's worlds. Worlds are saved as .emod files, written so that a crash in the middle of a save cannot damage them.

Bring your old worlds

Put an old .eden world (or a .zip or .gz of one) in the saves folder above. It shows up in the world list and converts the first time you play it; the original file is left alone. You can also export any world back to .eden from the Share screen.

Build it yourself

It is open source. The Developers page has the build steps.
