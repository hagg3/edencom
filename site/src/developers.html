Developers

What the code is

The 2.1.1 source of Eden: World Builder (Objective-C++, OpenGL ES 1.1, iOS), moved to plain C++20 on SDL3 and OpenGL, running on macOS, Linux, Windows and iOS. The engine lives in Classes/; platform glue sits in port/; the game binary is built from native/. Worlds are saved in an append-only .emod format, with .eden kept for import and export.

Build it

git clone {{github}}.git
cd edencom/native
cmake -B build -DCMAKE_BUILD_TYPE=Release -DEDEN_DIAGNOSTICS=ON
cmake --build build -j8
./build/eden_native

You need CMake and a C++20 compiler. Options, test modes (--*-selftest) and save locations are in native/README.md.

Contributing

Issues and pull requests are welcome on GitHub. Linux, Windows and iOS builds are only checked by the project's CI, so a green CI run on your branch matters. For a chat first, join the Discord.
