# C.1 gate 1 (WORKING/dev-console-plan.md §8): command-block parser equivalence, read by
# `eden_native --console-selftest` (--console-corpus=PATH; default ../port/tools/fixtures/cmds/corpus.txt).
#
# Each line is parsed twice: with the block options (CmdScript::parse) and with the console options
# (parseLine: no triggers, `=N` absolute coordinates, the selftest's stand-in registry with the verbs
# `echo`, `help` and `video.fov`). The first word says which of them accept it (0 bad statements):
#   B  both: the statement vectors must be field-equal (op, v, abs, type, color, hasPos, f, text, ext, args)
#   b  blocks only: the line must start with a trigger header, the console's only error is
#      "Triggers only work in a command block", and the rest is field-equal
#   c  the console only: every statement the block calls bad is a registry verb or uses `=`;
#      the rest is field-equal
#   x  neither
# '#' starts a comment line; blank lines are skipped. Sound bounds assume NUM_SOUNDS = 79.

# cmd.html: the examples
B say WELCOME TRAVELER;wait 1;set 0 3 0 lamp;gold 1
B set 0 3 0 glass
B set 5 0 0 stone
B tp 0 20 0
B set ~ ~3 ~ glass
